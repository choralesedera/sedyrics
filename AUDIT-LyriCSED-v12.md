# AUDIT LyriCSED v12

- Base : LyriCSED v11, sans retour à une ancienne version.
- Un seul lecteur audio global conservé.
- Catalogue et 28 chants conservés.
- Hira : disponibilité calculée dynamiquement parmi Lyrics / Playback / Solfa.
- Onglets absents : complètement masqués, pas seulement désactivés.
- Toutes les combinaisons sont supportées.
- Playback Hira : utilise toujours le lecteur audio global unique.
- Bouton Retour Android : fonction JS native-ready ajoutée.
- Confirmation de sortie : dialogue HTML intégré.
- Facebook : plus aucun intent:// généré côté HTML.
- Facebook : menu à deux choix ajouté.
- Communication APK/WebView : WebViewString.
- Design précédent conservé.
